# Лабораторная работа №3. Bubble

## Часть 1. Промпт и генерация каркаса

### Промпт (дословно)

> Создай приложение на тему «Палитра цветов» — сервис, где пользователь 
> может создавать, хранить и просматривать цветовые палитры для дизайна.
>
> Пусть этот сайт будет требующий регистрацию.
>
> Страницу обязательно создай по структуре header + body + footer:
> - header: логотип «Palette Studio» и навигация (Мои палитры, Создать палитру);
> - body: список палитр пользователя и форма добавления новой палитры;
> - footer: строка с копирайтом.
>
> Обязательно укажи в заготовке следующую строку: «ТВП: <Фамилия>».
>
> Добавь несколько интерактивных элементов (реализующих CRUD):
> - форма создания палитры (название + 3–5 цветов);
> - список существующих палитр с возможностью просмотра;
> - кнопки редактирования и удаления палитры.

### Результат генерации

Bubble AI сгенерировал приложение **Palette Studio** со структурой header + body + footer, 
навигацией и блоком цветных свотчей. Строка «ТВП: ...» присутствует в footer.
